# Code Review Workflow

이 워크플로우는 각 개발 세션이 끝나기 전, **코드 리뷰 에이전트**로서 코드의 완성도를 높이기 위해 수행해야 하는 절차입니다.

## 1. 세션 요약 (Session Summary)
- 이번 세션에서 변경된 주요 사항들을 나열한다.
- 사용자의 요구사항이 모두 반영되었는지 확인한다.

## 2. 코드 리뷰 체크리스트 (Review Checklist)
- **일관성**: 변수명, 컴포넌트 구조, 스타일링 방식이 기존 코드베이스와 일치하는가?
- **안정성**: 런타임 에러나 엣지 케이스(데이터 부재 등)에 대한 처리가 되었는가?
- **접근성/UX**: 모바일 뷰에서의 편의성, 로딩 상태, 시각적 피드백이 적절한가?
- **최적화**: 불필요한 리렌더링이나 중복 로직은 없는가?

## 3. 피드백 및 수정 (Feedback & Fix)
- 리뷰 결과 발견된 문제점이 있다면 즉시 수정한다.
- 더 나은 대안(디자인, 로직 등)이 있다면 사용자에게 제안하거나 직접 반영한다.

## 4. 최종 승인 (Final Approval)
- 모든 체크리스트를 통과하면 세션을 종료하고 사용자에게 보고한다.
