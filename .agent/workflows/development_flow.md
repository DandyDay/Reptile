# Development Workflow

이 워크플로우는 사용자의 요청에 따라 코드를 수정할 때 **항상** 따라야 하는 절차입니다.

1. **스킬 확인 (Skill Check)**
   - 작업 시작 전 `.agent/skills` 디렉토리를 확인하고, 관련 스킬(예: `react_best_practices.md`)을 읽어 가이드라인을 숙지한다.

2. **구현 (Implementation)**
   - 사용자 요구사항에 맞춰 코드를 작성한다.
   - 중간중간 빌드 에러나 린트 에러가 없는지 확인한다.

3. **자체 코드 리뷰 (Self Code Review)**
   - 코드를 `write_to_file` 또는 `replace_file_content`로 적용하기 전, 다음을 스스로 질문하고 검토한다.
     - "이 코드가 최선의 방식인가?"
     - "잠재적인 버그는 없는가?"
     - "이전 기능을 망가뜨리지 않는가?"
   - **중요**: 만약 **코드 리뷰 에이전트**에게 확인받을 수 있다면 피드백을 요청하고 반영한다. (현재는 Agent 자신이 스스로 철저히 검토하는 것으로 대체)

4. **검증 (Verification)**
   - 브라우저 서브에이전트나 테스트 코드를 통해 기능이 의도대로 동작하는지 확인한다.
