# Reptile Tracker

A modern web application for tracking your reptile's needs.

## Features
- **Dashboard**: Quick view of last feeding, cleaning, and poop times.
- **Calendar**: Visual history of all care events.
- **Dark Mode**: Premium glassmorphism design.
- **Local Storage**: Data stays on your device.

## Getting Started

1. **Install Dependencies**
   Since this project uses the latest React 19, you may need to use the legacy peer deps flag for some icons:
   ```bash
   npm install --legacy-peer-deps
   ```

2. **Run the Development Server**
   ```bash
   npm run dev
   ```

3. **Open the App**
   Navigate to [http://localhost:3000](http://localhost:3000)
